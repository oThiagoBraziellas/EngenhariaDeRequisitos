## 1. Quem utilizará o sistema?

Os usuários do sistema serão:

- Alunos
- Professores
- Coordenadores
- Diretores
- Pais ou responsáveis

## 2. Requisitos funcionais

1. Cadastro de alunos.
2. Lançamento e atualização de notas.
3. Emissão de boletim escolar.

## 3. Requisitos não funcionais

1. Segurança dos dados por meio de criptografia.
2. Acessibilidade para Pessoas com Deficiência (PCD).

## 4. Por que é importante levantar os requisitos antes de desenvolver um software?

Porque os requisitos dizem o que o sistema precisa fazer e para quem. Levantá-los antes evita construir algo que os usuários não precisam ou esquecer algo que eles precisam. Corrigir um erro de requisito na fase de levantamento custa muito menos do que corrigi-lo depois que o software já foi desenvolvido e entregue. Os requisitos também servem de base para planejar prazo e custo, dividir o trabalho da equipe e testar se o sistema entregue atende ao que foi pedido.
